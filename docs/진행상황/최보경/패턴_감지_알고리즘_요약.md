## 공통 처리 원칙

- 동일한 논리 이벤트에는 결정적으로 생성한 동일 `event_id`를 사용해 재처리 시 중복 생성을 방지한다.
- `ROUTINE_CHANGED`는 생활 패턴 변화 이력이며 위험 점수에는 반영하지 않는다.
- 관측 상태가 `INSUFFICIENT_DATA`인 날은 활동량 0으로 처리하지 않는다.
- `DATA_GAP` 또는 복구 확인 중에는 위험 이벤트 판단을 중단한다.
